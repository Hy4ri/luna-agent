# Nerd Font symbols

Symbols Nerd Font Regular, Nerd Fonts v3.4.0.

Source: https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/NerdFontsSymbolsOnly/SymbolsNerdFont-Regular.ttf

Converted to WOFF2 with fontTools; all glyphs are preserved. The web UI loads the split faces in `nerd/` (from `scripts/split-nerd-font.py`), so a page fetches only the glyph ranges it shows. Rerun the script after a font update. Used only for private-use project symbols. The U+F1105 glyph is `md-nix`.

See NERD-FONTS-LICENSE.txt for the upstream license.
